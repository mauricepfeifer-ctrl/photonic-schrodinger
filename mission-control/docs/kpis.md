# Key Performance Indicators (KPIs)

To ensure the "Money Path" works, we track the following metrics daily.

## 1. Activity (Inputs)

*Controlled by you.*

- **Outreach Volume**: Number of DMs/Emails sent. (Target: 20/day)
- **Content Pieces**: Number of posts/videos. (Target: 1/day)
- **Agent Uptime**: % of time your showcase agent is running without error. (Target: 99%)

## 2. Traction (Throughput)

*Market response.*

- **Response Rate**: % of people who reply. (Target: >10%)
- **Demo Requests**: Number of people saying "Send the video". (Target: 5/week)
- **Calls Booked**: Confirmed meetings. (Target: 3/week)

## 3. Results (Outputs)

*Business Health.*

- **Revenue**: Total EUR booked.
- **Cash Collected**: Total EUR in bank.
- **Delivery Time**: Hours spent fulfilling the service. (Target: Reduce by 50% via templates)

## How to Measure

- Use the **Mission Control Dashboard** to track technical KPIs (Uptime).
- Use a simple spreadsheet or Notion for Sales KPIs.
- Review every Sunday.
