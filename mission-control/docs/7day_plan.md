# 7-Day Money Path Execution Plan

## Goal: Close 1 Client for Package S (€1,500) or M (€4,500)

### Day 1: Research & Setup

- [ ] Define the specific "Expensive Problem" you solve (e.g., "Agency owners wasting time on lead lists").
- [ ] Build a "Lead Magnet" Agent (a simple n8n workflow that solves a small part of this).
- [ ] Scrape/List 50 qualified prospects.

### Day 2: Content & Soft Launch

- [ ] Record a Loom video: "How I automated [Problem] in 5 minutes".
- [ ] Post on LinkedIn/X: "Building a new agent for [Industry]. Who wants to accept the beta testers?"
- [ ] Send 10 DMs to warmest prospects.

### Day 3: Outreach (Volume)

- [ ] Send 20 Cold DMs / Emails using the scripts.
- [ ] Follow up on Day 2 comments.
- [ ] Goal: Book 3 Calls.

### Day 4: The Machine

- [ ] Iterate on your offer based on Day 3 replies.
- [ ] Refine the "Demo" (Mission Control Dashboard showing the agent working).
- [ ] Send 20 more DMs.

### Day 5: Sales Calls

- [ ] Conduct calls.
- [ ] **Pitch Script:** Diagnose -> Agitate Pain -> Show "Mission Control" Demo -> Offer Package.
- [ ] Handle Objections ("Is it secure?", "Will it break?").

### Day 6: Follow-Up & Content

- [ ] Post a "Case Study" or "Behind the Scenes" of your Mission Control.
- [ ] Follow up with Day 3/4 leads.

### Day 7: Review & Delivery

- [ ] Review KPIs (Calls booked, Revenue).
- [ ] If Client Secured: Start Onboarding (Phase 0 of their setup).
- [ ] If No Client: Analyze bottleneck (Offer? Outreach? Demo?) and restart cycle.
